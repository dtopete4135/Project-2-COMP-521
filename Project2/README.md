# Project 2 — Numerical Integration

This project implements 4 numerical-integration methods and applies them to blackbody radiation and limb-darkened planetary transits.

## Environment

The project was developed with Python 3.11 in the `comp521` Conda
environment.

Required packages:

- NumPy
- Matplotlib
- pytest
- Jupyter

To create a compatible environment:

```bash
conda create -n comp521 python=3.11 numpy matplotlib pytest jupyter
conda activate comp521
